**Subject: Timesheet System is Live — Please Start Logging Hours**

Hi team,

Our timesheet system is now live at **timesheet.wirbauensoftware.de**. Please log in with your email and the password **Changeme123!** — you'll be asked to change it on first login.

**Daily Time Logging**

Please log your hours every day. You can only add entries for today and the previous 2 days — anything older is locked, so don't fall behind. Each entry requires a description of what you worked on. Keep it brief but specific (e.g. "Built login page UI" not just "development").

You can also use the Clock In/Out feature at the top of the page. Select your project, clock in when you start, and clock out when you're done — it will create the time entry for you. If you switch projects during the day, you'll be prompted to describe what you did before switching.

**Leave Requests**

If you need to take leave, submit a request through the Leave page. Requests must be made at least 2 weeks in advance. I'll review and approve or reject them from my end.

**Project Assignment**

You'll only see projects you're assigned to. If you need to be added to a project, let me or Kian know.

**Questions & Bugs**

If you have any questions, message me or we can bring it up in the sync. If you run into bugs, let me know — this is our own system, so we can fix and adjust it however we need.
